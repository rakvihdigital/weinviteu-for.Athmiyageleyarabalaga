# Temple invitation (Next.js)

    npm install
    npm run dev        # http://localhost:3000

Deploy: push this folder to a GitHub repository and import it at vercel.com/new, or run `npx vercel` here. No settings or environment variables are needed.

- `lib/temple.js` — the whole 3D scene. All wording on the plaque, stones, emblem and coin is in the `CONTENT` block at the top.
- `components/TempleInvitation.jsx` — the page markup, including the opening welcome text.
- `public/altar.jpg`, `public/ganesha.jpg` — the two shrine images.
